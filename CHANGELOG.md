- 3 анкеты за 5 минут (по умолчанию). Исправлена ошибка: раньше проверка сравнивала UTC с локальным временем и не срабатывала.
- Отдельный лимит на вопросы вне анкеты (по умолчанию 3 за 5 минут).
- Оба лимита и окна времени меняются в /admin → «Антиспам».

### Вопросы
- После отправки анкеты сообщение осталось, кнопки «Да/Нет» убраны.
- Любой текст вне анкеты цитируется + «Вы уверены что хотите задать этот вопрос?» с кнопками Да/Нет. «Нет» — сообщение бота удаляется, «Да» — вопрос уходит админам.
- Команда /ask — «Изложите свой вопрос, мы обязательно свяжемся с вами.»

### Меню команд
- Пользователи видят только /start и /ask. Админы — плюс /admin.
- Старые команды /bans, /add_admin, /remove_admin, /list_admins, /cancel работают, но скрыты.

### Админ-меню (/admin)
- **Актуальные анкеты** — список заявок «новые + в работе»; под списком каждая анкета ответом на исходную с кнопками «Готово / Отмена / В работу».
- Статус помечается сверху и снизу анкеты у всех админов: ❓ — не обработана, 🕐 — в работе, ✅ — готово, ❌ — отмена. Готовые/отменённые пропадают из актуальных.
- **Редактирование моделей** — выбор существующей марки или «Добавить новую модель». Бот присылает шаблон — скопировать, поправить, отправить. Ветка сразу появляется в анкете. Есть удаление марки.
- **Чёрный список** — просмотр, разбан, добавление по ID.
- **Антиспам** — отдельно для анкет и для вопросов: время (1/5/10/30/60 мин) и лимит (1/2/3/5/10).
- **Администраторы** — добавить/удалить по ID. Kirill и Dima встроены, удалить их нельзя.

### Запуск и структура
- Убран выбор админов в консоли (ломал запуск и давал «database is locked»). Запуск без вопросов, консоль показывает логи.
- БД и лог перенесены в `data/`; старая `holsters_bot.db` из корня переносится автоматически при первом запуске.

# Деплой на BotHost

1. **Архив.** Запакуйте содержимое папки бота в `.zip` (можно вместе с корневой папкой). Не кладите `venv`, `__pycache__`, `data/` — БД создастся сама.
2. **Создать бота.** bothost.ru → «Создать бота» → загрузка архива.
   - Платформа: Telegram, язык: Python, библиотека: aiogram.
   - Главный файл: `main.py` (задан и в `bothost.json`).
   - Bot Token: токен от @BotFather.
3. **Переменные окружения** (панель бота). Обязательна только `BOT_TOKEN` (если не указана в форме). Файл `.env` из архива тоже подхватится, но токен лучше держать в панели.
4. **Запуск.** BotHost сам поставит зависимости из `requirements.txt` и запустит бота. В логах должно быть: `Бот запущен`.
5. **Проверка.** Напишите боту /start. Админам — /admin (если меню команд не появилось, сначала отправьте /start).
6. **Данные.** БД лежит в `data/holsters_bot.db` — эта папка на BotHost сохраняется между обновлениями. Перенести старые заявки: загрузите свой `holsters_bot.db` в `data/` через файловый менеджер панели.
7. **Обновление.** Загрузите новый архив → «Пересобрать». `data/` не трогается.

**Если не стартует:** смотрите логи работы (не сборки). Частые причины — не задан `BOT_TOKEN`, указан не тот главный файл, этот же токен одновременно запущен на ПК (ошибка `Conflict: terminated by other getUpdates`) — остановите локальный бот.

**Локально (Windows):** `pip install -r requirements.txt`, затем `run_bot.bat`.

# Структура

```
main.py                    точка входа
config.py                  версия, токен, встроенные админы, тексты, стартовый каталог
bothost.json               настройки для BotHost
requirements.txt
CHANGELOG.md               этот файл
handlers/order_handlers.py анкета, вопросы вне анкеты, /start, /ask
handlers/admin_handlers.py /admin и все его разделы, статусы анкет
models/database.py         SQLite
services/order_service.py  отправка анкет админам, статус-метки
services/message_service.py отправка вопросов админам
services/bot_commands.py   меню команд (пользователи / админы)
utils/keyboard.py          клавиатуры
utils/states.py            FSM-состояния
data/                      БД и лог (создаётся автоматически)
*.bat                      запуск/автозапуск на Windows
```
